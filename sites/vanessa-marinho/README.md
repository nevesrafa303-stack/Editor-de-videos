# Site — Dra. Vanessa Marinho

Landing page estática (HTML + CSS, sem build). Abra `index.html` no navegador
ou publique a pasta inteira (Netlify, Vercel, GitHub Pages, Hostinger...).

## Antes de publicar
1. **WhatsApp:** em `index.html`, troque `const WHATSAPP = "55XXXXXXXXXXX"` pelo número real (55 + DDD + número).
2. **Fotos:** as imagens em `img/` foram recortadas de prints do Instagram — substitua pelos arquivos originais em alta resolução, mantendo os mesmos nomes.
3. **Antes/depois:** confirme que existe autorização por escrito do paciente e revise os textos com a Dra. conforme o Código de Ética do CFO.
4. Confira endereço/cidade da clínica (não incluídos por falta da informação).
