# Roteiros com ganchos fortes · Plano de saúde em São Paulo pelo CNPJ (21/11/2026)

Sete roteiros de 41 a 48 s para uma pessoa falar direto para a câmera, no tom dos vídeos da Bradesco que editamos.
Vieram depois do retorno do cliente sobre os simples: "um pouquinho maior e com ganchos fortes".

**Ganchos:** cada um usa um gatilho diferente:
- ordem direta;
- erro comum;
- segredo;
- frase polêmica;
- número;
- promessa de tempo;
- identificação.

Cada um tem um gancho alternativo para teste A/B.

**Estrutura:**
1. Gancho (0–3 s).
2. Promessa de continuação.
3. Dor.
4. Solução pelo CNPJ.
5. Benefícios.
6. Hospitais de São Paulo.
7. "Exclusivo para CNPJ ou MEI, a partir de 3 vidas".
8. CTA do formulário.

**Tamanho:** cerca de 2,7 palavras por segundo. Cada roteiro tem de 111 a 132 palavras.

**Regras:**
- **Hospitais:** sempre "dependendo do plano". Quem vier pelo anúncio recebe uma cotação com o hospital citado.
- **Economia:** só "pode", "muitas vezes", "outra regra de preço". Nenhum valor ou percentual sem cotação real.
- **Ranking:** Newsweek/Statista 2026 conforme o `CLAUDE.md`: 1º Einstein, 2º Sírio-Libanês, 3º Oswaldo Cruz no Brasil.
- **Observações obrigatórias:** só na tela, com o texto exato. A lista de cada roteiro está no fim.
